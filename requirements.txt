# GUI Calculator Requirements
# This calculator uses Python's built-in tkinter library
# No additional dependencies required beyond Python 3.x

# For systems where tkinter is not included by default:
# On Ubuntu/Debian: sudo apt-get install python3-tk
# On CentOS/RHEL: sudo yum install tkinter
# On macOS: tkinter is included with Python
# On Windows: tkinter is included with Python
